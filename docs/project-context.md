# 钢贸上下游数据平台：项目背景与已确认决策

相关文档：[需求文档](./steel-trade-data-platform-requirements.md)

## 目标

为货袋子平台新增一个板块：钢贸行业上下游数据平台。下游钢贸企业通过 ERP 调用平台接口上传销售与库存数据，上游钢厂付费查看聚合后的数据。

## 固定约束

- 平台需支持海量数据。
- 下游钢贸企业（数据上传方）至少 20000 家，上游钢厂（数据购买方）至少 500 家。
- 后端 Java，前端 Vue3。
- 作为货袋子平台的一个板块融入，货袋子平台现状信息尚未提供（见需求文档第 22 章）。
- 上游只能看聚合数据，看不到单家企业明细。
- 只向上游收费，按下游企业数计费，支持批量购买。

## 业务方已确认的决策（2026-11-24）

编号对应需求文档第 21 章。

## 原型范围（2026-11-24 确认）

- 高保真 HTML 原型覆盖三端：上游钢厂端、下游钢贸端、平台运营后台。
- 视觉风格先用通用的企业级后台风格，之后再向货袋子对齐。

## 原型评审中确认的规则（2026-11-25）

- 订阅期内加购名额：从新增下游企业的生效日起计费，下单日到生效日之间不收费。新增企业仍按数据池调整规则在下一周期生效。
- 价格功能尚未对上游开放时，企业名单和选购名录里的“是否提供价格数据”一列隐藏，开放后再显示。需求文档中 UP-01 与 UP-70 的冲突按此统一。
